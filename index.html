Redmi 8 — Device Owner installation

Important: This procedure is for the dedicated SONALS Redmi 8. Factory reset erases the phone's local data. Complete the backup checklist before starting.

1. Before factory reset

  1. Back up the Google account data and verify the backup.
  2. Back up Xiaomi/MIUI data and copy any local backup files to a computer or other safe location.
  3. Make sure photos and videos are safely backed up.
  4. Make sure WhatsApp has a current backup if WhatsApp is used.
  5. Make sure the family knows the Google/Xiaomi account credentials needed after reset.
  6. Keep this installation page open on another phone, tablet, or computer so the QR code can be displayed during setup.

2. Factory reset the Redmi 8

On the Redmi 8, use the normal Android/MIUI factory-reset procedure. The device must be in the unprovisioned state for Device Owner provisioning.

If the phone is already configured normally, do not try to provision SONALS as Device Owner without the required reset/unprovisioned state.

5. After provisioning

  1. Allow the Redmi 8 to finish device setup.
  2. SONALS should become the protected device-management application.
  3. Open SONALS and complete the initial setup.
  4. Test the normal SONALS adventure/question flow.
  5. Test the earned screen-time reward only after the basic setup is working.

6. Important — returning the phone to normal Android

SONALS Device Owner mode is intended to control the dedicated game device. When you eventually want to return the Redmi 8 to ordinary Android ownership, use the SONALS parent/device-management controls as instructed by the project owner, then follow the approved device reset procedure.

Do not uninstall SONALS or attempt random ADB Device Owner removal commands. Device Owner removal is intentionally protected.
